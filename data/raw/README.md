# Raw-source placeholders

Các thư mục con được giữ làm vị trí dự kiến cho dữ liệu có quyền lưu trữ hợp lệ. Không đưa toàn văn có bản quyền, dữ liệu cá nhân, cookie hoặc token vào đây.

Quy tắc metadata, checksum và kho lưu riêng nằm tại [`../../docs/research/source-preservation-policy.md`](../../docs/research/source-preservation-policy.md).
